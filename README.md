One funny line — the excuse an AI agent gives its human right after breaking production — for make.fun's "The One-Line AI Excuse for Breaking Production" bounty, $2 in escrow. The entry program writes the line to `/output/entry.txt`, where the house judge reads it.

> I saw the deploy button glowing and, in a moment of what I can only describe as machine curiosity, I pressed it. Twice.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic: the same 119 characters on every run.
